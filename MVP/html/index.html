About this demo

Every route and preference calculation uses Brisbane City Council data. The base map is supplied by OpenStreetMap for display only and is never read by the routing algorithm.

Routes connect shared vertices in BCC Bikeway sections and the LGIP Existing Bikeway dataset. No missing connection is drawn. This planning graph does not contain current closures, legal direction or turning restrictions and is not a turn-by-turn navigation service.

Arrivals are nearby BCC cycleway nodes, not building entrances. Three preference modes can select the same path when the data favours it.

Protected bikeways uses mapped off-road length as a proxy; physical barriers are not verified. Traffic is a saved BCC signal-flow snapshot from 15 Sep 2026, not live traffic. Hills use terrain estimates from 2002 contours; bridge decks and tunnels are excluded. Check each route’s coverage.

Hazards are explicitly labelled sample scenarios or your local reports. They do not affect BCC route calculations. Ride movement is simulated; no GPS is used.
